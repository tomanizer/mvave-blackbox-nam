# Project instructions

This repository researches native NAM on the M-Vave Blackbox. At the initial baseline there is no working firmware or verified Blackbox recovery path.

Read the README, claim register and relevant roadmap tasks before edits. Keep observations, upstream reports and proposals distinct. Use precise part numbers and citations. An FM-1 address, pinout or installer is not a Blackbox result.

Keep model support explicit. Record the runtime revision, architecture, configuration, sample rate and target measurements. Do not describe format conversion as network compression or architecture conversion.

Do not perform hardware writes as part of documentation or offline analysis. Firmware work requires the recorded Blackbox-specific backup/recovery prerequisites. Never publish private dumps or user/device credentials.

Use straightforward prose. Make narrow checks appropriate to the change; do not add a large test or CI framework for documentation edits.
